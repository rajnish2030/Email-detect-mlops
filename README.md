# Email Spam Detection
An AI-powered email spam detection system using Hugging Face Transformers, PyTorch, FastAPI, and MLOps.

## Features
- Detects Spam and Not Spam emails
- Uses a pretrained Hugging Face Transformer model
- FastAPI backend
- HTML + Tailwind CSS frontend
- Model prediction API
- MLOps-ready project structure
- Prediction history and model monitoring

## Technologies
- Python
- Hugging Face Transformers
- PyTorch
- FastAPI
- Pandas
- Scikit-learn
- MLflow
- Docker
- HTML
- Tailwind CSS
